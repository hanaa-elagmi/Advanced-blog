# Simple Website Interface Project using HTML, CSS & JavaScript

## 📝 Project Idea:
This is a basic static web page that includes:
- A header with a **responsive navigation menu**.
- Main content with sections like Home, About, Contact, and Portfolio.
- A **Back to Top** button that appears on scroll.
- A **simple contact form** in the footer.
- Performance optimizations like non-blocking CSS/JS loading.

The goal of this project is to practice **Flexbox layout**, **external CSS styling**, and **basic interactivity with JavaScript**.

## 📁 Project Structure:

```
📁 project-folder/
│
├── index.html              ← Main HTML file
├── style.css               ← External CSS with variables and color improvements
├── script.js               ← JavaScript functions (menu toggle, back to top)                 
└── README.md               ← Project description
```

## ▶️ How to Run:

1. Download or clone the project files.
2. Open `index.html` in your browser (Chrome, Firefox, Edge, etc.).
3. Try toggling the menu on smaller screens or scrolling to test the "Back to Top" button.

## 📌 Notes:

- No server or installation is needed — this is a static HTML project.
- The script uses the `defer` attribute for optimized JavaScript loading.
- Helpful comments are included in the code for easier understanding and editing.
